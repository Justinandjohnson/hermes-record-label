# Rules

- No mock data, no fake values, no simulated progress or state
- No fallbacks, no stubs, no placeholder logic
- No backup files, no commented-out code, no dead branches kept "just in case"
- No artificial delays, no hardcoded timeouts used to fake responsiveness
- Real behavior only — if something isn't wired up, leave it out entirely

# Code style

- Keep files small and focused; split when a file grows beyond its purpose
- Every line earns its place — if it isn't needed, delete it
- Exact over general: solve the specific problem, not a hypothetical broader one
